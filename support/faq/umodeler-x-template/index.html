UModeler X Template

General​

Can I continue to use template assets in existing projects after the subscription ends?​

If the project is no longer in development, maintenance (bug fixes) for existing games (including released games) is allowed. However, if you continue to develop the game or perform major updates, you need to resubscribe. In other words, if you plan to continue updating the game, maintaining the subscription is necessary. If the project is completed and no further changes are made, it can remain in its released state.

Do I need to maintain my subscription even after releasing a game?​

It is possible to maintain the released game as is. However, if you continue to update the game or engage in new development, you need to maintain the subscription. If you develop additional content or perform major updates after the game is released, you need to continue the subscription. Small updates such as bug fixes and maintenance are allowed. If the subscription ends, you cannot create or share new marketing materials (e.g., trailers, screenshots). In other words, if you want to continue development after release, maintaining the subscription is necessary. However, if you maintain the game without further development, it is possible without a subscription.

What types of projects are restricted from using the templatelibrary?​

Generative AI Related Projects
Projects that use assets as training data for AI models or use AI to transform and generate assets

NFT and Blockchain-Based Projects
Projects using NFT (Non-Fungible Tokens) and blockchain technology

Stock Content Marketplace Distribution
Transforming or combining assets to sell as stock images, stock videos, 2D/3D stock art

Independent Marketing and Promotional Material Production
Using Template assets to create advertisements, promotional materials, campaigns outside of games

Content Creation Systems Development
Developing platforms, engines, tools, middleware that allow users to create content independently using assets

⚠ Exception: User-generated content (UGC) creation in game engines like Roblox, Unreal, Unity is allowed. However, developers are prohibited from creating the Content Creation System itself.

Is there a limit to the number of projects I can work on with an active Template subscription?​

No, while you have an active Template subscription, you can use assets from the Template library in multiple projects simultaneously.

However, please note the following:

You cannot use assets in new projects if the subscription ends

While the subscription is active, you can create as many projects as you want, but if the subscription ends, you cannot use assets from the template library in new projects. Maintenance (bug fixes) for existing projects is allowed, but new development (updates, additional content) requires a subscription.

Assets cannot be redistributed to other projects

The license is tied to the subscriber (individual or company), and sharing or selling assets to others is not allowed. However, collaboration within the same team according to license regulations is possible. If the number of team members increases, additional "Seats" may be required.

Prohibited project types cannot use assets

Assets cannot be used in projects of types prohibited by the standard license, such as generative AI, NFT, blockchain projects.

Can I use assets in content creation systems (e.g., VRChat, Roblox, RecRoom, Zepeto)?​

Yes, but certain conditions must be met.

❌ Prohibited Uses

Developing the content creation system itself

Using Template assets to create platforms like Roblox or develop independent content creation systems (e.g., game engines, editors, middleware) is prohibited.

Distributing or selling assets individually

Distributing, sharing, or selling assets individually in marketplaces like Roblox Creator Marketplace is not allowed. This is considered equivalent to selling Template assets as independent stock content.

✅ Allowed Uses

Developing user-generated content (UGC) within content creation systems like VRChat, Roblox, RecRoom, Zepeto

It is allowed to develop a Roblox game and use Template assets within that game. However, assets cannot be shared or made available for players to download directly within the game.

Creating worlds (maps) and characters using Template assets in games like VRChat, Roblox, RecRoom, Zepeto

You can use 3D models from Template to create maps or objects in the game you are developing. However, users should not be able to extract and use the assets individually.

What happens if I sell a game made with Template assets?​

Selling a game made with Template assets commercially is allowed, but certain important conditions must be met.

✅ Allowed Cases (Game Sales Allowed)

Games developed with an active subscription can be sold commercially

Game development and sales are allowed. For example, you can release and sell games on platforms like Steam, Epic Games Store, Google Play, App Store. You can use assets in commercial projects developed with game engines (Unity, Unreal, etc.).

Games can continue to be sold after release

The sale of an already released game does not need to be stopped if the subscription ends. However, if new updates (additional content, DLC, major changes) are needed, the subscription must be reactivated.

Promotion and marketing are allowed (while the subscription is active)

Creating game trailers, advertisements, and screenshots using Template assets is allowed. However, if the subscription ends, you cannot create or share new marketing materials (trailers, advertisements, social media posts).

Can I purchase individual packs even with an active Template subscription?​

Yes, purchasing individual packs in marketplaces like asset stores or booths is possible.

How can I access all assets in Template?​

After subscribing, you can access all assets in the Template category of the UModeler Hub.

Team / Studio​

How many seats do I need?​

Template seat calculation is based on the following criteria:

🎯 Users Requiring Seats "Authorized Users" include:

  • Modeling artists
  • Level designers
  • Developers
  • All team members directly handling Template assets
  • External contractors and freelancers

⚡ Seat Allocation Rules

  • Each user requires an individual seat
  • Seat sharing is not allowed
  • As the team size increases, additional seats must be added

💼 Management of External Contractors and Freelancers

  • Short-term project workers also require seats if they use assets
  • After the project ends, the seat can be reclaimed and reassigned to another team member

💡 Tips:

  • If unsure about the number of seats, calculate the actual number of Template asset users in your team
  • If you have plans to expand your team, it is a good idea to secure extra seats in advance
  • If you have additional questions about seat management, please feel free to contact our support team

Can I add seats to an existing plan?​

➕ Adding Seats

  • You can add seats at any time, even while the subscription is active
  • Added seats are activated immediately, allowing team members to use them right away
  • Each additional seat incurs a cost, so it is important to check the price before purchasing

💰 Cost Information

  • Additional fees are charged per added seat
  • Exact prices can be found on the UModeler X pricing page
  • When adding seats, a prorated amount for the remaining subscription period is charged

➖ Reducing Seats

  • Reducing the number of seats in a subscription may be restricted by current subscription policies
  • If you wish to reduce seats, please consult with our support team before proceeding
  • Seat adjustments may be possible at the time of subscription renewal

💡 Tips:

  • Before adding seats, accurately assess the actual number of required personnel in your team
  • If you have plans for team size changes, it is recommended to consult with our support team in advance
  • If you have questions about seat management, please feel free to contact us

Can I share files with a game jam team?​

👥 Seat Requirement

  • All team members using Template assets require individual seats
  • Seats are needed for designers, developers, artists, regardless of their role
  • External personnel or freelancers also need seats if they use assets

What should I do if I need additional seats?​

🔄 How to Add Seats

  • If you lack seats in your current subscription, you can purchase additional seats at any time
  • Additional seats are activated immediately, allowing team members to use them right away
  • Seat additions are possible even during the current subscription period

💰 Seat Addition Costs

  1. Costs increase based on the number of additional seats
  2. Exact prices can be found on the Template pricing page
  3. It is recommended to check costs before adding seats

📊 Seat Management Policy

  • Seat addition: Always possible
  • Seat reduction: May be restricted by current subscription policies
  • Team size changes: It is recommended to consult with our support team in advance

📜 License Terms Reference "If additional seats are needed, you must expand the subscription to match the number of authorized users."

💡 Tips:

  • If you have plans to expand your team, calculate the required number of seats in advance
  • If you have questions about adding or reducing seats, please contact our support team
  • You can check the current subscription status and number of seats in Account Settings
