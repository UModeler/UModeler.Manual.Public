UModeler X Plus

1.0.38 | August 12, 2025​

  • New Features
    • Painting Mode
      • Copy Layer: Right-click on a mask or paint layer to copy its content (excluding alpha) to the clipboard. Also available via Ctrl+C / Command+C.
      • Paste Layer: Right-click to paste an image from the clipboard onto a mask or paint layer (excluding alpha). Also available via Ctrl+V / Command+V.
      • Invert Layer: Right-click to invert the colors of a mask or paint layer.
  • Improvements
    • General
      • Reduced delay when loading scenes or reloading scripts with many UModelerXEditableMesh objects in the scene.
    • Modeling Mode
      • Display Mode:
        • Display settings (X-Ray, Checkered) previously spread across individual tools have been consolidated under UMX Display Settings.
        • Toggle via shortcuts: Alt+X, Alt+V.
        • The classic RulerGrid material has been reintroduced as part of display options.
      • Element Overlay:
        • Vertex and edge visibility options are now available in UMX Display Settings via Alt+Z.
      • Multi Object Tool:
        • A new tool allowing Unity's built-in transform functions (e.g., move) while multiple objects are selected.
    • Painting Mode
      • Sticker Layer: Default background color is now set to white.
  • Bug Fixes
    • General
      • Fixed occasional errors during OBJ export.
      • Fixed an issue where .OBJ imports failed to retain materials on multi-material meshes.
      • Prefab Editor: Fixed an issue where prefabs containing inactive objects would sometimes fail to save.
      • Fixed a bug where backface edges appeared in overlays.
      • Fixed a rendering error in Rigging Meshes.
      • Fixed an issue where UModelerize FBX did not work on meshes without rigging.
    • Modeling Mode
      • Detach Tool and Separate Parts Tool: Fixed a bug that left holes in the original face after operation.
    • Modifiers
      • Mirror Modifier: Fixed non-functional click-to-move mirror plane.
    • UV Editor
      • Auto Alignment Tool: Fixed abnormal Undo behavior.
    • Painting Mode
      • Rect Fill: Fixed edge painting issue when Triangle option was disabled.

      • Fixed an error that occurred when pressing Delete with a modifier selected.
    • UV Editor
      • General: Fixed an issue where the gizmo was not visible if IsSnap could not be used.
      • LSCM Tool: Fixed a crash that occurred on certain meshes.
