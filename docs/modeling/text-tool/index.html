Text Tool

The Text Tool is used to create 2D vector-based text objects (splines). It allows you to enter a string and adjust properties such as font, size, alignment, and spacing to visually place the text within the scene.

How to use​

  1. Select the Text tool.

  1. Choose the desired Font.

  1. Type the desired text.

  1. Click and drag in the scene to create text at the desired size.

  1. When the text is at the intended size, click to finish mesh creation.

  1. Adjust the Text Tool properties, then either select an element or switch to another tool to complete the process.

One Click Build and Edit via Properties​

  1. Select the Text tool.

  1. Enter the desired values in the Text Tool properties.

  1. Click the One Click Build button to add the shape to the scene.

  1. Further adjust the Text Tool properties, then either select an element or switch to another tool to finish.

Properties​

Font​

Choose a font installed on your system.

Text​

Enter the string to display.

Width​

Sets the width of the text.

Height​

Sets the height of the text.

Top​

Adjusts the scale based on the top of the text.

Bottom​

Adjusts the scale based on the bottom of the text.

Left​

Adjusts the scale based on the left side of the text.

Right​

Adjusts the scale based on the right side of the text.
