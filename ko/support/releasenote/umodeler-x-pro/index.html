UModeler X Pro

1.1.8 | 2025년 6월 11일​

  • 새 기능
    • Painting 2D
      • 마우스 우클릭 및 드래그로 Axis, Grid, Texture, Wireframe을 회전할 수 있습니다.
  • 개선
    • UV Editor
      • Pack Tool
        • Pack 기능 사용 시, UVIsland 의 크기가 실제 mesh의 크기에 비례하게 사이즈가 변경됩니다.
        • Padding 속성으로 각 UVIsland 사이의 간격을 조절할 수 있습니다.
      • Fit Tool : 전체 UV 레이아웃에 적용되는 전역 여백을 설정할 수 있습니다.
  • 버그 수정
    • 일반
      • 프리팹 에디트 종료 시 몇몇 언두 커맨드가 삭제되지 않는 문제를 수정했습니다.
    • Modeling Mode
      • Favorite Tool
        • 우클릭 했을 때 툴 UI가 뜨지 않는 현상을 수정했습니다.
        • 이미 한쪽에서 선택되어 있는 툴을 다른 쪽에서 선택되지 않는 문제를 수정했습니다.
      • Face Tool : 노말 계산이 잘못되는 문제를 수정했습니다.
      • Knife Tool / PolyLine Tool : 카메라 회전을 위해 드래그 할 때 툴 사용이 종료되는 문제를 수정했습니다.
      • PushPull Tool : PushPull 툴 진행 후 바로 전 행동이 프로퍼티로 조정 안되는 문제를 수정했습니다.
      • Linear Array Tool : 생성된 메쉬에 Multi UV Channel 이 적용되지 않는 현상을 수정했습니다.
      • Radial Array Tool : 생성된 메쉬에 Multi UV Channel 이 적용되지 않는 현상을 수정했습니다.
      • Mirror Object Tool
        • 생성된 메쉬에 Multi UV Channel 이 적용되지 않는 현상을 수정했습니다.
        • UV가 생성되지 않은 Mesh에서 실행 시 오류가 발생하는 현상을 수정했습니다.
    • Painting 3D Mode
      • Brush Tool : UV의 경계면에 브러시가 칠해지지 않는 오류를 수정했습니다.
    • UV Editor
      • Vertex Mode 에서 Handle이 표시되지 않는 현상을 수정했습니다.

1.1.7 | 2025년 5월 30일​

  • 새 기능
    • 일반
      • Tool Input Hint
        • 씬 좌측 상단 EdMesh Info 하단에 Tool Input Hint 버튼이 추가됩니다. 버튼을 누르면 현재 툴에서 사용 가능한 기능과 단축키가 표시됩니다. 이 버튼은 환경 설정에서 끄고 켤 수 있습니다.
    • Modeling Mode
      • Edge Flip Tool
        • 선택된 면들의 삼각화 방향을 전환시켜주는 기능입니다.
  • 개선 사항
    • .obj 파일을 import 시, import 옵션을 설정할 수 있습니다.
    • 하이 폴리곤 상태에서 선택, 피킹, Decimate Modifier, 메시 빌드 등에서 속도 개선이 되었습니다.
    • UModelerize
      • 이제 UModelerize가 복사본을 생성하지 않습니다. 대신 원본을 바로 UmodelerX 오브젝트로 만듭니다. 예외는 FBX, OBJ의 프리팹 인스턴스입니다. 원본을 수정할 수 없는 인스턴스 특성 상 언팩 이후 UModelerize 해야합니다.
      • 프로젝트 뷰에서 FBX를 바로 UModelerize 할 수 있습니다. UModelerX > UModelerize FBX 메뉴를 통해 사용할 수 있습니다. FBX의 데이터를 담은 새로운 프리팹이 생성됩니다.
    • Scene Toolbar
      • 환경설정의 “Enable Scene Toolbar” 옵션을 통해 완전히 가려지지 않은 버튼이 전부 가려지도록 수정했습니다.
    • Rigging Mode
      • Disable GPU Option에 대한 설명이 추가되었습니다.
    • Favorite Tool
      • 기본 Favorite Tool 목록에 Pivot, Reset X Form 툴이 추가되었습니다.
  • 버그 수정
    • Modeling Mode
      • 몇몇 툴에서 Manual 연결이 되지 않는 문제를 수정했습니다.
      • Stair Tool 생성 시 uv가 비정상적으로 생성되는 문제를 수정했습니다.

1.1.6 | 2025년 5월 23일​

  • 새 기능
    • Rigging Mode
      • Human Avatar Tool
        • Body Bone Auto Setup : 본의 이름을 체크해 Human Body Bones 세팅을 자동으로 해주는 기능입니다. 유니티 필수 본을 기준으로 실행됩니다.
        • Clear Body Bone Data : 설정된 Human Body Bones 세팅을 전부 삭제합니다.
  • 개선 사항
    • Modeling Mode
      • Delete GameObject : 이제 Delete 버튼을 눌렀을 때 게임 오브젝트가 삭제됩니다. Element Tool에서 Element를 선택 후 Erase를 실행하는 경우만 예외입니다.
      • Escape Tool : 마우스를 우클릭하면 오브젝트 툴로 나가도록 개선하였습니다. 조금이라도 드래그 한다면 동작하지 않습니다. PolyLine, Kinfe 툴의 경우 사용 중인 상태를 빠져나갑니다.
    • Painting Mode
      • Color Spoid : 2D 및 3D Painting의 칼라 스포이드 기능이 개선되었습니다. 이제 Brush Tool, Fill Tool에서 ‘I’ 키를 사용하면 스포이드가 등장하고 색을 가져올 수 있습니다. 화면에 보이는 색과 동일한 색을 가져오도록 개선했습니다.
    • Rigging Mode
      • Build Bone Tool : Turn 90 버튼이 삭제됩니다. 바인드 포즈 설정을 좀 더 명확히 하기 위한 조치입니다. 앞으로 휴머노이드 리깅 시 정면을 기준으로 시작하여야 합니다. Human 구조의 본 이름을 유니티 아바타 부위의 이름과 일치하도록 수정했습니다.
      • Rigging Tool : 빈 곳을 클릭했을 때 본 선택이 해제됩니다.
  • 버그 수정
    • Modeling Mode
      • Rectangle Tool : 기존 페이스 위에서 작동시 수치조절할때 발생하는 문제를 수정했습니다.
      • Disk Tool : 기존 페이스 위에서 작동시 수치조절할때 발생하는 문제를 수정했습니다.
      • SideStair Tool : 기존 페이스 위에서 작동시 수치조절할때 발생하는 문제를 수정했습니다.
      • Bridge Tool : 연결된 두 개의 Edge를 선택 했을 때 Bridge가 실행되지 않는 문제를 수정했습니다.

1.1.5 | 2025년 5월 13일​

  • 개선 사항
    • Rigging Mode
      • WeightBrushTool : Backface Select가 추가되었습니다. 해당 옵션을 켜면 브러시가 통과하는 모든 버텍스에 영향을 끼칩니다.
  • 버그 수정
    • 일반
      • FaceColor, UVParams 데이터가 특정 툴 사용 시 유지되지 않는 현상을 수정했습니다.
    • Modeling Mode
      • FaceTool : 특정 상황에서 Extrude가 기즈모 방향대로 동작하지 않는 문제를 수정했습니다.
      • Subdivide Tool : 언랩된 페이스 사용시 나타나는 에러를 수정했습니다

1.1.4 | 2025년 5월 7일​

  • 버그 수정
    • 일반
      • 작은 폴리곤에서 피킹이 안되는 문제를 수정했습니다.
      • UModelerize Merge Vertex에서 머지 범위를 추가했습니다. 해당 범위 내에 있는 점은 동일한 점으로 인식합니다
      • Delete UMX Components
        • 기능을 사용 후 씬을 다시 열면 컴포넌트가 존재하는 현상을 수정했습니다.
        • 기능을 사용 후 Undo/Redo 시 오류가 발생하는 현상을 수정했습니다.
    • Modeling Mode
    • MultiObject Editor
      • Combine Tool : Multi UV가 적용되지 않는 문제를 수정했습니다.
    • Modifier
      • MirrorModifier : 미러 모디파이어 선택 상태에서 삭제 후 언두시 나오는 에러를 수정했습니다.
    • UV Editor
      • UVIsland에서 일부분 선택취소시 제대로 적용이 안되는 문제를 수정했습니다.
    • CurveMesh
      • Volume Tool : Rotate 프로퍼티 조정 시 발생하는 에러를 수정했습니다.

1.1.3 | 2025년 4월 28일​

  • 개선
    • Rigging Mode
      • Avatar가 적절하게 설정되지 않은 상태에서 Rigging 툴을 사용할 때 오류 창 대신 경고 로그가 출력되도록 개선했습니다. 로그에 설정이 필요한 본이 표시됩니다.
    • UVEditor
      • Scale Gizmo : 기즈모의 스케일 비율을 조정하였고 최소값이 0 이하로 내려가지 않도록 수정했습니다.
  • 버그 수정
    • 일반
      • 이미 씬에 프리팹이 둘 이상일때 해당 프리팹을 씬에 배치된 프리팹이 아닌 오브젝트로 덮어쓰기 프리팹화를 하면 데이터가 날라가는 문제를 수정했습니다.
      • 과거 UModelerX 버전의 모델을 불러오는데 생기는 오류를 수정했습니다.
      • 메시 빌드시 EdgeSeam에서 나타나는 레이스 컨디션 문제를 수정했습니다.
      • 유니티 PolyBrush 패키지의 충돌 문제를 수정했습니다.
      • 가끔 새롭게 패키지를 설치할 때 선택 색상이 흰색으로 나오는 문제를 수정했습니다.
      • SkinnedMesh를 Umodelerize할 때 Avatar 설정과 관련해 발생하는 오류를 수정했습니다.
    • Rigging Mode
      • 본 구조가 수정될 때 본에 담긴 몇몇 데이터가 잘못된 본으로 복사되는 버그를 수정했습니다.
    • CurveMesh
      • Alt+Ctrl+좌클릭을 통해 매뉴얼 페이지로 이동하지 못하는 문제를 수정했습니다.

1.1.2 | 2025년 4월 18일​

  • 버그 수정
    • 일반
      • Prefab 인스턴스의 하위 오브젝트를 복사 후 저장할 경우, Prefab이 삭제되는 현상을 수정했습니다.
    • Modeling Mode
      • Inset Tool : 프로퍼티 값을 수정하는 도중 Undo/Redo시 커맨드 시스템이 문제생기는 부분을 수정했습니다.
      • Bevel Tool : 연속해서 툴을 실행할 때 발생하는 문제를 수정했습니다.
      • Multi Mirror Tool : UmodelerX가 아닌 오브젝트와 함께 선택했을 때 발생하는 문제를 수정했습니다.
      • Repeat Tool : 버텍스에 Bevel Tool을 재실행 할 때 오버레이가 사라지는 문제를 수정했습니다.
      • Material Tool : Material 변경 실행 취소 후 재실행 할 때 Material이 갱신되지 않던 문제를 수정했습니다.
    • UV Editor
      • UV 형태가 일정하지 않은 페이스를 회전할 때 흔들림이 발생하는 문제를 수정했습니다.
    • CurveMesh
      • Delete 키로 커브 점을 삭제할 때 오브젝트가 함께 삭제되는 현상을 수정했습니다.

1.1.1 | 2025년 4월 9일​

  • 개선 사항
    • Modeling Mode
      • Parallel Tool : 조작 후 Distance 수치를 수정하면 바로 전에 만든 Parallel을 조작 할 수 있습니다.
    • CurveMesh : Closed 형태인 CurveMesh의 끝 부분의 연결을 좀 더 부드럽게 개선했습니다.
  • 버그 수정
    • 일반
      • Unity 2023.1 버전에서 Import시 snapEnabled 관련하여 발생하는 에러를 수정하였습니다.
      • Sticker Layer를 포함한 Editable Mesh를 Prefab화 할 때 발생하는 에러를 수정했습니다.
    • Modeling Mode
      • Erase Tool : 엣지 혹은 버텍스를 삭제할때 주변 UV 상황에 따라 발생하던 에러를 수정했습니다.
      • PushPull Tool : 홀이 없어질때 생기는 문제를 수정했습니다.
      • UV Param Tool : Drawing Gruop 의 작업이 일어날때 최대한 유지하도록 수정되었습니다.
      • Face Color Tool : Drawing Gruop 의 작업이 일어날때 최대한 유지하도록 수정되었습니다.
    • Painting3D
      • Rect Fill : mask 레이어에서 브러쉬 모양이 나오는 문제를 수정했습니다.
    • UVEditor
      • UVFace 에서 드래그로 선택할 때 홀에 있는 UV가 선택되지 않는 문제를 수정했습니다.
      • Unwrap Cancel Tool : Cancel작업을 언두 할때 생기는 문제점을 수정했습니다.
    • MultipleObject
      • Mirror Tool : 툴 사용 이후 비활성화된, 프리팹 오브젝트를 선택했을 때 생기는 문제를 수정했습니다.

1.1.0 | 2025년 4월 1일​

  • 새 기능
    • Modeling Mode
      • Text Tool
        • 주어진 텍스트로 Mesh를 생성하는 툴입니다.
      • Edge Constraints
        • Vertex 및 Edge를 Edge를 따라서 이동하는 옵션이 추가되었습니다.
      • Quadify Tool
        • Mesh의 일부 혹은 전체에 대해서 사각화하는 툴입니다.
      • Isolate Tool
        • 독립적인 mesh 단위로 선택할 수 있습니다.
    • Multiple Objects
      • Multi Align Tool
        • 여러 개의 오브젝트를 기준에 맞춰 정렬할 수 있습니다.
    • Curve Mesh Component
      • 곡선 형태의 메쉬를 생성하는 컴포넌트가 추가되었습니다. 곡선을 이루는 점의 생성, 제거, 이동을 활용해 곡선의 형태를 만들고 타입과 부피를 조절해 원하는 방식으로 생성할 수 있습니다.
      • 매뉴얼 페이지(https://docs.umodeler.com/docs/curve-mesh)에서 추가적인 사용법을 확인해주세요.
