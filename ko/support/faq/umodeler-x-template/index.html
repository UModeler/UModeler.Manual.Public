UModeler X 템플릿

일반​

구독이 종료된 후에도 기존 프로젝트에서 템플릿 에셋을 계속 사용할 수 있나요?​

프로젝트가 더 이상 개발 중이 아니라면, 출시된 게임을 유지보수(버그 수정)하는 것은 허용됩니다. 그러나 게임 개발을 계속하거나 주요 업데이트를 진행할 경우, 다시 구독해야 합니다. 즉, 게임을 계속 업데이트할 계획이라면 구독을 유지해야 합니다. 프로젝트가 완료되어 더 이상의 변경이 없다면, 출시된 상태로 유지할 수 있습니다.

게임을 출시한 후에도 구독을 유지해야 하나요?​

출시된 게임은 현재 상태로 유지 가능합니다. 그러나 게임을 계속 업데이트하거나 새로운 개발을 진행할 경우, 구독을 유지해야 합니다. 게임 출시 후 추가 콘텐츠 개발이나 주요 업데이트를 진행한다면 구독이 필요합니다. 버그 수정이나 유지보수 같은 소규모 업데이트는 허용됩니다. 단, 구독이 종료된 경우에는 새로운 마케팅 자료(예: 트레일러, 스크린샷)를 제작하거나 공유할 수 없습니다. 즉, 출시 후에도 개발을 계속하려면 구독을 유지해야 하지만, 단순 유지보수만 진행한다면 구독 없이도 가능합니다.

템플릿 라이브러리를 사용할 수 없는 프로젝트 유형은 무엇인가요?​

생성형 AI 관련 프로젝트
에셋을 AI 모델의 학습 데이터로 사용하거나, AI를 활용하여 에셋을 변형 및 생성하는 프로젝트

NFT 및 블록체인 기반 프로젝트
NFT(대체 불가능 토큰) 및 블록체인 기술을 사용하는 프로젝트

스톡 콘텐츠 마켓플레이스 배포
에셋을 변형하거나 조합하여 스톡 이미지, 스톡 비디오, 2D/3D 스톡 아트로 판매하는 행위

게임 외의 독립적인 마케팅 및 홍보 자료 제작
템플릿 에셋을 활용하여 게임 외의 광고, 홍보물, 캠페인 등을 제작하는 행위

콘텐츠 제작 시스템 개발
사용자가 에셋을 활용해 콘텐츠를 독립적으로 제작할 수 있는 플랫폼, 엔진, 툴, 미들웨어 등을 개발하는 행위

⚠ 예외: Roblox, Unreal, Unity와 같은 게임 엔진 내의 UGC(사용자 생성 콘텐츠) 제작은 허용됩니다. 단, 콘텐츠 제작 시스템 자체를 개발하는 것은 금지됩니다.

템플릿 구독이 활성 상태인 동안 몇 개의 프로젝트에 사용할 수 있나요?​

제한 없이 여러 프로젝트에서 동시에 템플릿 라이브러리의 에셋을 사용할 수 있습니다.

단, 다음 사항을 유의해 주세요:

구독이 종료되면 새로운 프로젝트에서 에셋을 사용할 수 없습니다

구독이 활성화되어 있는 동안에는 얼마든지 프로젝트를 생성할 수 있지만, 구독이 종료되면 새로운 프로젝트에서 템플릿 에셋을 사용할 수 없습니다. 기존 프로젝트에 대한 유지보수(버그 수정)는 허용되지만, 새로운 개발(업데이트, 추가 콘텐츠 등)을 위해서는 구독이 필요합니다.

에셋을 다른 프로젝트로 재배포할 수 없습니다

라이선스는 구독자(개인 또는 회사)에 귀속되며, 에셋을 다른 사람에게 공유하거나 판매하는 것은 금지됩니다. 단, 라이선스 규정에 따라 동일한 팀 내에서 협업은 가능합니다. 팀원이 늘어날 경우 추가적인 "시트(Seats)"가 필요할 수 있습니다.

금지된 프로젝트 유형에는 에셋을 사용할 수 없습니다

생성형 AI, NFT, 블록체인 등 표준 라이선스에 의해 금지된 프로젝트 유형에는 에셋을 사용할 수 없습니다.

콘텐츠 제작 시스템(예: VRChat, Roblox, RecRoom, Zepeto)에서 에셋을 사용할 수 있나요?​

네, 특정 조건을 충족하는 경우 사용 가능합니다.

❌ 금지된 사용 예

콘텐츠 제작 시스템 자체를 개발하는 경우

Roblox와 같은 플랫폼을 직접 만들거나, 독립적인 콘텐츠 제작 시스템(예: 게임 엔진, 에디터, 미들웨어 등)을 개발하는 데 템플릿 에셋을 사용하는 것은 금지됩니다.

에셋을 개별적으로 배포 또는 판매하는 경우

Roblox Creator Marketplace와 같은 마켓플레이스에서 에셋을 개별적으로 배포하거나 판매하는 것은 허용되지 않습니다. 이는 템플릿 에셋을 독립적인 스톡 콘텐츠로 판매하는 것과 동일하게 간주됩니다.

✅ 허용된 사용 예

VRChat, Roblox, RecRoom, Zepeto 등 콘텐츠 제작 시스템 내에서의 UGC(사용자 생성 콘텐츠) 개발

Roblox 게임을 개발하고, 해당 게임 내에서 템플릿 에셋을 사용하는 것은 허용됩니다. 단, 에셋을 플레이어가 직접 다운로드하거나 추출하는 것은 허용되지 않습니다.

VRChat, Roblox, RecRoom, Zepeto 등의 게임에서 템플릿 에셋을 사용해 월드(맵)나 캐릭터 제작

템플릿의 3D 모델을 사용해 맵이나 오브젝트를 제작하는 것은 가능합니다. 단, 사용자가 에셋을 개별적으로 추출하거나 사용하는 것은 허용되지 않습니다.

템플릿 에셋으로 만든 게임을 판매해도 되나요?​

템플릿 에셋을 사용해 제작한 게임의 상업적 판매는 다음 조건을 충족하면 가능합니다.

✅ 허용되는 경우 (게임 판매 가능)

활성화된 구독 하에 개발된 게임은 상업적으로 판매 가능

예를 들어 Steam, Epic Games Store, Google Play, App Store 등에서 게임을 출시 및 판매할 수 있습니다. Unity, Unreal 등 게임 엔진으로 개발된 상업 프로젝트에서 에셋 사용이 가능합니다.

출시된 게임은 구독 종료 후에도 판매 가능

이미 출시된 게임은 구독이 종료되어도 계속 판매할 수 있습니다. 단, 새로운 업데이트(추가 콘텐츠, DLC, 주요 변경 등)를 진행할 경우 구독을 다시 활성화해야 합니다.

마케팅 및 프로모션은 구독이 활성 상태일 때 가능

게임 트레일러, 광고, 스크린샷 등 템플릿 에셋을 활용한 마케팅 자료 제작은 구독이 활성 상태일 때만 가능합니다. 구독이 종료된 경우, 새로운 마케팅 자료(트레일러, 광고, SNS 게시물 등)를 제작하거나 공유할 수 없습니다.

구독이 활성 상태여도 개별 팩을 따로 구매할 수 있나요?​

네, 에셋 스토어나 부스 등의 마켓플레이스에서 개별 팩을 구매하는 것도 가능합니다.

템플릿의 모든 에셋은 어디서 확인할 수 있나요?​

구독 후, UModeler Hub의 Template 카테고리에서 모든 에셋에 접근할 수 있습니다.

팀 / 스튜디오​

몇 개의 시트(Seats)가 필요한가요?​

템플릿 시트 계산 기준은 다음과 같습니다:

🎯 시트가 필요한 사용자
"인증 사용자"에는 다음이 포함됩니다:

  • 모델링 아티스트
  • 레벨 디자이너
  • 개발자
  • 템플릿 에셋을 직접 다루는 모든 팀원
  • 외부 계약자 및 프리랜서

⚡ 시트 배정 규칙

  • 사용자 1명당 시트 1개 필요
  • 시트 공유는 불가
  • 팀 규모가 증가하면 시트를 추가해야 함

💼 외부 계약자 및 프리랜서 관리

  • 단기 프로젝트 인원도 에셋을 사용한다면 시트가 필요
  • 프로젝트 종료 후 시트를 회수하여 다른 팀원에게 재할당 가능

💡 팁:

  • 시트 수가 헷갈릴 경우, 실제 템플릿 에셋 사용 인원을 기준으로 계산하세요
  • 팀 확장을 계획 중이라면, 미리 여분의 시트를 확보하는 것이 좋습니다
  • 시트 관리에 대해 추가 질문이 있다면 고객지원팀에 문의해 주세요

기존 플랜에 시트를 추가할 수 있나요?​

➕ 시트 추가

  • 구독이 활성화된 동안 언제든지 시트를 추가할 수 있습니다
  • 추가된 시트는 즉시 활성화되며, 팀원이 바로 사용할 수 있습니다
  • 추가 시트는 별도 비용이 발생하므로 구매 전 가격을 꼭 확인하세요

💰 비용 정보

  • 시트 1개당 추가 요금이 부과됩니다
  • 정확한 가격은 UModeler X 가격 페이지에서 확인할 수 있습니다
  • 구독 기간 중간에 시트를 추가할 경우, 남은 기간에 대한 일할 계산이 적용됩니다

➖ 시트 감소

  • 구독 정책에 따라 시트 수 감소는 제한될 수 있습니다
  • 시트를 줄이고자 할 경우, 먼저 고객지원팀과 상담해 주세요
  • 시트 조정은 구독 갱신 시점에 가능할 수 있습니다

💡 팁:

  • 시트 추가 전, 팀 내 실제 필요 인원을 정확히 파악하세요
  • 팀 규모 변경 계획이 있다면 미리 상담받는 것이 좋습니다
  • 시트 관리 관련 문의는 언제든 고객지원팀에 문의해 주세요

게임잼 팀과 파일을 공유할 수 있나요?​

👥 시트 필요 조건

  • 템플릿 에셋을 사용하는 모든 팀원은 각각의 시트가 필요합니다
  • 역할에 상관없이 디자이너, 개발자, 아티스트 모두 시트 필요
  • 외부 인력 또는 프리랜서도 에셋을 사용하는 경우 시트 필요

추가 시트가 필요하면 어떻게 해야 하나요?​

🔄 시트 추가 방법

  • 현재 구독에서 시트가 부족한 경우, 언제든지 추가 구매가 가능합니다
  • 추가된 시트는 즉시 활성화되며, 팀원이 바로 사용할 수 있습니다
  • 구독 기간 중에도 시트를 추가할 수 있습니다

💰 시트 추가 비용

  1. 추가하는 시트 수에 따라 비용이 증가합니다
  2. 정확한 가격은 템플릿 가격 페이지에서 확인 가능합니다
  3. 추가 전 반드시 가격을 확인하는 것이 좋습니다

📊 시트 관리 정책

  • 시트 추가: 항상 가능
  • 시트 감소: 구독 정책에 따라 제한될 수 있음
  • 팀 규모 변경: 고객지원팀과 사전 상담 권장

📜 라이선스 조항 참고
"추가 시트가 필요한 경우, 인증 사용자 수에 맞게 구독을 확장해야 합니다."

💡 팁:

  • 팀 확장 계획이 있다면, 필요한 시트 수를 미리 계산해 두세요
  • 시트 추가 또는 감소에 대한 문의는 고객지원팀으로 연락 주세요
  • 현재 구독 상태 및 시트 수는 계정 설정에서 확인할 수 있습니다
