I cannot sign up.​

  • Conflict(409) Error occurs.

    This occurs when the email or Username is already in use by another user. Please try using a different email address or Username.

  • I received an error message saying "An error occurred whil sending the request." while signing up. What does this mean and how can I resolve it?

    This error typically indicates a problem in the communication process between the system sending the request and the server that's supposed to receive it. Common causes include:

    • Network Issues: A poor or unstable internet connection can interrupt the data transmission.

    • Firewall or Security Settings: Sometimes, firewall or security settings might block requests.

    • How to Resolve:

      • Check Your Internet Connection: Ensure that your internet connection is stable.
      • Wait and Retry: Sometimes waiting a few minutes and retrying can resolve the issue if it's related to temporary server overload or downtime.
      • Check System Settings: Ensure that your firewall and security settings are not blocking the request.
      • Contact Support: If the problem persists, reach out to the support team of the service you're using for specific assistance.
      • Support team email : contact.support@umodeler.com

      Remember, the exact solution might vary depending on the specific context of the error.

  • I haven't received the verification email, and I'm getting a 'Not Acceptable (406)' error message.

    Please check if your antivirus firewall program is running. If it is, please disable this firewall program during the registration process and give it another try.

  • Is it a valid email?

    Only users who receive our service's sent email can use the service. Occasionally, the reception of the email we sent may be blocked by the email service provider.

  • Did the email arrive in the spam folder?

    Please check if the email sent by our service is in the spam folder. Our service no longer sends emails if the user cannot properly receive emails. If the email has arrived in the spam folder, please take action so that it is no longer classified as spam.

I cannot log in.​

  • Please check the verification email sent after signing up.

    Are you unable to log in, seeing a page like the one below?

    • Invalid email page screen

      If so, please check whether a verification email has arrived at the email address you used for your account. If you didn't receive it, check your spam folder and complete the verification process.

      If there is no verification email in the spam folder, there's a possibility that it was blocked by your email provider. Please contact the person in charge for help.

  • Please check if your internet connection is stable.

    The login function is available in an environment where internet connection is possible.

  • Check if it is a corporate internet environment or an HTTP Proxy environment.

    In some corporate internet environments, you may need to ask your network administrator to allow access to the https://api.umodeler.com domain. However, our service does not yet support HTTP Proxy settings. We plan to support HTTP Proxy settings in the near future.

When I enter the invoice number or order ID on the UModeler X Plus unlock page, an Internal Server Error (500) occurs.​

This issue usually occurs when the hub is already logged in. It can be resolved by logging out and then logging back in.

You can log out of the UModeler Hub by clicking the Sign Out button as shown below.

I cannot download the package.​

  • Are you an authenticated user?

    Package downloads are only available to authenticated users. You can download packages only with a login-enabled account.

    If the problem persists, your authentication may have expired. Log out and log in again to verify.

Package download takes too long.​

  • You may need to check the quality of your internet service.

    Our service uses a CDN to provide stable package download speeds from the geographically closest server for all countries around the world.

    Typically, download times may be longer due to limitations in user internet bandwidth or speed.

    In this case, please contact your internet service provider.

It seems like I can't access the service.​

  • Do you need a corporate internet environment or HTTP Proxy settings?

    In some corporate internet environments, contact your network administrator to access our service. Our service does not currently support HTTP Proxy settings. We plan to support HTTP Proxy in the near future.

The problem still persists.​

To help resolve the issue, please send an email inquiry to contact.support@umodeler.com or contact the UModeler X Discord server issue forum(link).

We will do our best to resolve the issue as soon as possible.

An error occurs during the account creation process, stating “Illegal byte sequence encountered in the input. Parameter name: string”.​

It has been determined that this error occurs when non-English characters are included in the following items:

  • Unity Project Path
  • Windows Computer Name (PC or Computer name)

You can check the computer name by entering hostname in the command prompt as shown below.

To change the computer name, you can do so in the Windows Settings panel using the Rename this PC feature. You can open the *Settings panel by pressing the Windows button and typing Settings.

Therefore, please try changing the names of these items to English and then attempt again.

Here is the reference page for this issue.

  • https://github.com/mono/mono/issues/7117
  • https://github.com/BepInEx/BepInEx/issues/407
  • How to change the pc name in Windows 11
