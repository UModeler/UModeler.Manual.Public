UModeler X Pro 출시 및 2025년 1분기 업데이트 소식

2025년 3월 29일 · 약 10분
황재식
Founder and CEO

UModeler X Pro 출시 및 2025년 주요 업데이트 소식

Unity 기반 3D 콘텐츠 제작을 혁신하는 UModeler X가 드디어 Pro 라이선스를 출시합니다. 더 강력한 모델링 기능, 전문가를 위한 고급 툴셋, 그리고 100만원 상당의 고품질 템플릿 라이브러리를 포함한 Pro는 모든 3D 크리에이터와 팀에게 완성도 높은 제작 환경을 제공합니다.

이번 블로그에서는 UModeler X Pro의 상세 구성과 가격, 기존 Plus 버전의 유지방향, 교육기관을 위한 School 라이선스, 향후 로드맵, 에반젤리스트 활동, 그리고 2025년 1분기 업데이트 소식을 모두 정리해드립니다.

UModeler X Pro 라이선스: 전문가를 위한 고급 모델링 솔루션​

UModeler X Pro는 고급 사용자와 팀을 위한 프리미엄 라이선스로, 모델링의 효율성과 정밀도를 모두 만족시키기 위해 설계되었습니다.

요금제​

  • 월 구독: ₩29,000/월 USD 20/월
  • 연 구독: ₩290,000/년 USD 199/년
  • UModeler의 공식 웹사이트에서 더욱 상세한 정보를 확인하실 수 있습니다.

포함 기능​

  • UModeler X Plus의 모든 기능
  • 1차 Pro 전용 확장 기능
    • Curve Mesh 컴포넌트: 곡선 기반 3D 메쉬 제작
    • Text 툴: 3D 텍스트 메쉬 생성
    • Quadify 툴: 삼각형 폴리곤을 사각형 기반으로 변환
    • Edge Constraints: 정점이나 엣지를 원래의 형상을 유지하며 연결된 엣지를 따라 이동시키는 기능
    • Isolation 선택 툴: 독립 영역 선택

지속적인 기능 업데이트​

  • Pro 사용자에게는 신규 고급 기능이 지속적으로 추가됩니다.

₩1,000,000 상당의 템플릿 라이브러리 제공​

  • Unity Asset Store에서 판매 중인 고품질 3D 에셋들을 무제한으로 사용 가능
  • 모든 에셋은 UModeler X 프리팹으로 제공되어 Unity에서 바로 편집 및 배치 가능
  • 템플릿 페이지에서 더 많은 정보를 얻을 수 있습니다.

기존 UModeler X Plus 라이선스​

UModeler X Plus는 지금까지 많은 사용자들이 사용해온 기능 중심의 모델링 도구로, 다음과 같은 강력한 툴셋을 포함하고 있습니다.

요금제​

  • 라이프타임 요금제
  • 자금규모 20만달러 마만의 조직 및 개인
  • 유니티 에셋 스토어에서 UModeler X Plus에 대한 더 많은 정보를 확인하실 수 있습니다.

주요 기능​

  • 필수 3D 모델링 기능
  • 모디파이어
  • UV 에디터
  • 리깅 기능
  • 핫스팟 텍스처링 시스템
  • 2D/3D 페인팅
  • 스케치업 스타일 모델링 기능 등

향후 방향성 및 Pro와의 관계​

UModeler X Plus는 Pro와 동일한 코드 베이스를 공유합니다. 즉, Pro는 Plus 위에 구축된 확장형 버전으로, Plus의 모든 기능을 포함하고 그 위에 고급 기능이 추가된 형태입니다.

✅ Plus의 모든 기능은 Pro와 동일한 속도와 품질로 지속적으로 업데이트됩니다.

✨ Plus는 안정성과 장기 유지보수에 중점을 둔 종합 모델링 솔루션으로서의 역할을 계속해 나갑니다.

🔁 새로운 기능 추가보다는, 현재 구현된 기능의 안정성과 유지보수 강화에 주력할 예정입니다.

Plus를 사용하고 계신다면 안심하셔도 됩니다 — Plus는 앞으로도 지속적으로 지원되며, 여러분의 도구는 계속 개선될 것입니다.

School 라이선스: 학교 학생 및 교사를 위한 무료 지원​

UModeler X는 교육 현장의 창작 역량 향상을 위해 전 세계 학생과 교사/강사에게 무료 School 라이선스를 제공합니다.

대상​

  • 초·중·고·대학교의 학생 및 교육자

신청 방법​

  • 학교 도메인 이메일을 이용해 간단히 신청
  • School 라이선스 신청 페이지

사용 조건​

  • 교육 및 학습, 과제 수행에 한해 비상업적 목적으로만 사용 가능

에반젤리스트 '인디 게임 허슬'​

그동안 UModeler X를 활용한 유익한 튜토리얼 영상을 제작해온 유튜버 '인디 게임 허슬'이, 2024년 2월부터 공식 UModeler X 에반젤리스트로 활동하게 되었습니다.

초보자부터 중급 사용자까지 누구나 쉽게 따라할 수 있는 튜토리얼을 통해, UModeler X의 접근성을 높이고 실제 활용 사례를 소개하며 유저 커뮤니티와의 소통을 강화하고 있습니다.

  • 추천 영상

앞으로도 다양한 튜토리얼, 인사이트, 예제 콘텐츠가 꾸준히 업로드될 예정입니다.

인디 게임 허슬 전체 영상으로 바로 가기

2025년 1분기 업데이트 요약​

2025년 1분기 동안 총 12회의 업데이트(v1.0.8 ~ v1.0.19)가 진행되었습니다. 그 중 가장 주목할 만한 개선 사항은 다음과 같습니다.

SketchUp 스타일 모델링 고도화​

  • Parallel 툴, Arc 툴 추가
  • Polyline 툴의 XY 축 스냅 기능 추가
  • 기존 UModeler 대비 약 90% 이상 구현 완료
  • 복잡한 내부 구조를 기반으로 한 스케치업 스타일 툴의 안정화 완료

스케치업 스타일 모델링 소개
Arc 툴 데모 영상 보기

  • Group Filter 추가로 페인팅의 정확도 향상
  • Smoothing Sharp Edge 기능으로 엣지의 부드러운 표현 가능

Favorites 그룹 도입​

  • 자주 사용하는 툴만 모아 빠르게 접근 가능
  • SketchUp 스타일 툴셋이 기본으로 설정되어 있어 초보자도 쉽게 접근 가능

베타 기능 아이콘 도입​

초록색 물약 아이콘은 해당 툴이 베타 단계에 있음을 나타냅니다. 베타 단계란 내부 구현과 기본적인 테스트를 마친 후, 사용자에게 처음 공개된 상태로, 안정성이나 완성도 면에서 아직 개선이 필요한 툴을 의미합니다. 이 단계의 툴은 일부 기능이 예상대로 작동하지 않을 수 있습니다. 현재는 주로 SketchUp 스타일 툴, Pro의 Text 툴, Curve Mesh Editor 등이 베타로 지정되어 있으며, 정식 기능으로 자리잡기 위해 지속적인 개선 작업이 진행 중입니다.

홈페이지 및 매뉴얼 개편​

이번 Pro 출시에 맞춰서 홈페이지와 매뉴얼도 함께 리뉴얼되었습니다.

  • 공식 홈페이지

    • unity.umodeler.com

  • 새로운 상위 메뉴 추가

    • Template 메뉴 : 템플릿 에셋 전체 소개
    • Support 메뉴 : 문제 해결, 자주 묻는 질문, 활용 팁 제공

마무리하며​

UModeler X는 초보자도 손쉽게 시작할 수 있으면서, 전문가에게도 강력한 확장성을 제공하는 차세대 Unity용 3D 모델링 솔루션입니다.

Pro의 출시를 시작으로, UModeler X는 더욱 정교한 툴과 탄탄한 지원, 실용적인 리소스를 제공하며 진화해 나갈 것입니다.
