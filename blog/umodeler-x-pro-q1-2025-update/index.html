UModeler X Pro Release and Q1 2025 Update

UModeler X, the innovative 3D content creation tool for Unity, proudly introduces its Pro License. Equipped with powerful modeling features, advanced tools for professionals, and access to a premium 3D template library valued at over USD 700, the Pro license is designed to empower both individual creators and teams.

This blog post outlines the full details of the UModeler X Pro license, its pricing, direction for the existing Plus version, the free School license for educators and students, our release roadmap, evangelist activities, and a summary of the major updates completed during Q1 2025.

UModeler X Pro License: Advanced Modeling for Professionals​

UModeler X Pro is a premium license crafted for advanced users and creative teams. It delivers both high efficiency and precision in modeling workflows.

Pricing​

  • Monthly subscription: USD 28/month USD 20/month
  • Annual subscription: USD 280/year USD 199/year
  • Visit the official UModeler website for more details.

Features​

  • Includes all features from UModeler X Plus
  • 1st wave of exclusive Pro features:
    • Curve Mesh Component: For creating organic and curved 3d meshes
    • Text Tool: Generate 3D text meshes
    • Quadify Tool: Convert triangle-based meshes to quad-based meshes
    • Edge Constraints: Allow vertices or edges to move along connected edges while preserving the original shape
    • Isolation Selection Tool: Select specific areas easily

Continuous Feature Updates​

  • Pro users will receive regular updates with newly developed advanced features, many of which are released in beta for early access.

USD 700 Worth of 3D Template Library Included​

  • Unlimited access to premium 3D assets sold individually on the Unity Asset Store
  • All assets are provided as UModeler X prefabs, ready to be edited and used directly within Unity
  • Learn more on the Template Page

UModeler X Plus License​

UModeler X Plus has been a robust modeling toolset used by many creators, offering a comprehensive feature set with long-term support.

Pricing​

  • Lifetime license
  • For individuals and teams with an annual revenue under $200,000
  • Learn more at the UModeler X Plus page on the Unity Asset Store

Key Features​

  • Essential 3D Modeling tools
  • Modifiers
  • UV editor
  • Rigging tools
  • Hotspot texturing system
  • 2D/3D Painting
  • SketchUp-style modeling tools and more

Future Direction and Relationship with Pro​

UModeler X Plus shares the same codebase as Pro. In other words, Pro is an extended version built on top of Plus — it includes all the features of Plus along with advanced capabilities.

✅ All Plus features will continue to receive updates at the same pace and quality as Pro.

✨ Plus will continue to serve as a comprehensive modeling solution focused on stability and long-term maintenance.

🔁 Rather than adding new features, we will prioritize strengthening the stability and maintaining the functionality that has already been implemented.

If you're using Plus, rest assured — it will remain fully supported and your tools will continue to improve.

School License: Free for Students and Educators​

To support creative education, UModeler X offers a free School license to students and educators around the world.

Eligibility​

  • Students and faculty at elementary, middle, high schools, and universities

How to Apply​

  • Sign up using your school domain email
  • Visit the School License Application Page

Conditions​

  • For non-commercial use only, such as education, learning, and assignments

Q1 2025 Update Highlights​

During the first quarter of 2025, UModeler X received 12 major updates (v1.0.8 ~ v1.0.19). Here are the highlights:

SketchUp-Style Modeling Improvements​

  • Parallel Tool, Arc Tool added
  • XY-axis snapping implemented in the Polyline Tool
  • Over 90% feature parity achieved compared to the classic UModeler
  • SketchUp-style tools are now stable and ready for production use

Learn more about SketchUp-style modeling
Watch the Arc Tool demo

  • Group Filter feature for precise painting control
  • Smoothing Sharp Edge for cleaner and softer edge rendering

Favorites Tool Group​

  • Organize your most-used tools into a personal favorites group
  • Default setup includes SketchUp-style tools for beginner-friendly modeling

Beta Feature Tags​

The green potion icon indicates that a tool is currently in beta. Beta tools have completed internal implementation and basic testing, and are now available for public use. However, they may still require improvements in terms of stability and polish. As such, some features of these tools might not behave as expected. Currently, tools like the SketchUp-style modeling tools, the Pro Text Tool, and the Curve Mesh Editor are marked as beta. These tools are under active development and will continue to be refined until they are production-ready.

Website & Manual Updates​

Alongside the Pro launch, we've redesigned our website and documentation for better usability.

  • Official Website

    • unity.umodeler.com

  • New Navigation Sections

    • Template Menu: Overview of all template assets
    • Support Menu: FAQs, troubleshooting, tips and more

Final Words​

UModeler X continues its mission to make 3D content creation more accessible for solo creators and more powerful for professionals.

With the launch of Pro, ongoing updates, community engagement, and educational support, UModeler X is evolving into a comprehensive modeling solution for Unity.

Thank you for being on this journey with us.
Let's keep building amazing things together!
